MileSprout Perks

Reach drivers on shift. Pay only when a code is used.

MileSprout is a mileage tracker for couriers, delivery riders and self-employed drivers. The app's Perks tab is where they'll find deals from partners like you: say, a coffee between drops, a cheaper car wash or a discount on parts. You only pay when a driver uses your code.

Request the partner deck

How it works

Pay per use

A driver claims your offer in the app and gets a one-off code. You pay only when that code is used at your till or checkout. Claims that aren't used cost you nothing.

Claimed at the till

An in-store code works for a short window once claimed, typically 30 minutes, and you set it. So drivers claim it when they're with you, not days before.

A weekly cap you set

You decide how many codes you'll pay for each week. When the week's codes are gone, the offer says so until next week. Your spend never runs past the cap.

Back in the pool

A code that runs out without being used goes back into that week's pool for another driver, and doesn't count against the driver who let it lapse.

One per person

You set how often one person can have your offer: once a day, a week or a month. Each code is single-use, with check digits so staff can spot a mistyped one.

Private by design

Codes carry nothing about the driver, their trips or their phone. You get totals only (codes claimed and used), never names, locations or anyone's driving.
